トップ / Aoi Tools

WEB TOOL / UI DESIGN / AI-ASSISTED DEVELOPMENT

Aoi Tools

Web制作で感じた小さな不便を解消するために、3つのWebツールを企画・制作しました。ツールごとに目的や必要な技術が異なるため、要件やUIは自分で整理し、実装ではCodexを積極的に活用しています。

  • 企画・要件整理
  • UI設計
  • 実装支援
  • 公開・改善

目的

Web制作の中で発生する「UIパーツを探す」「ワイヤーフレームを作る」「複数画面幅を確認する」といった作業を手軽にすることから制作を開始しました。

UIパーツを探す→ページ構成を組む→画面幅を確認する

それぞれの作業に合わせ、Webパーツ図鑑、Wireframe Maker、Responsive Preview LabをAoi Tools内の3つのツールとしてまとめています。

自分が担当したこと

企画・設計

ツールの目的や必要な機能、画面構成、UI、操作方法を決めました。実際に使って改善点を判断し、生成された実装も画面とコードで確認しています。

確認・改善

実際に操作し、表示や動作を確認。操作の分かりやすさと、制作現場で使う理由があるかを基準に改善しました。

AIを使ったこと

Codexは実装支援、コード生成、修正に使っています。Wireframe MakerではReact、TypeScript、Vite、Zustandなどを使う実装も補助します。目的・仕様・UI・改善の判断は自分で行い、生成された内容を確認して仕上げます。

工夫と判断

実装できる機能を増やすのではなく、「実際に使うか」を基準に機能を整理しました。Responsive Preview Labでは当初の6画面構成から、390px / 1440px中心の2画面構成へ変更し、日常的な確認に必要な比較へ絞っています。

ツールごとに目的を分け、Aoi Toolsの中にまとめることで、制作の流れに沿って使い分けられるようにしました。

3つのWebツール

  • Webパーツ図鑑
  • Wireframe Maker
  • Responsive Preview Lab

結果

3つのWebツールを企画から公開まで制作しました。AIによって実装範囲を広げながら、UIや仕様の判断に時間を使えるようにしています。

ツールを開く: Webパーツ図鑑 · Wireframe Maker · Responsive Preview Lab
